使用说明与架构

访问方式

在客户端 hosts 中配置：

<Docker 主机 IP>  www.qytdocker2026.com
<Docker 主机 IP>  kibana01.qytdocker2026.com

使用浏览器访问 https://www.qytdocker2026.com（需信任实验 CA 证书）。

日志链路

Nginx → access-compose.log → Filebeat（共享卷）→ Elasticsearch → Kibana。在 Kibana 中创建 Index Pattern 后，可按 URI、status、referer 等字段做 Discover 与 Dashboard。
